🏟️ Arena AI Wrapper
☁️ Vercel edition

Chat with Arena's models

This Vercel deployment talks to arena.ai with your logged-in account and answers like an API. The first message after a while can take 10–30 seconds (the browser starts fresh each time).

If chats fail with LOGIN_REQUIRED, the Arena session has expired: re-run npm run session-for-vercel in the main project and update the ARENA_SESSION_B64 env var, then redeploy.
